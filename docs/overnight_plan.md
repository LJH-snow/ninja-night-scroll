# 过夜开发计划

- 计划日期：2026-09-30 夜间至 2026-10-01
- 项目：忍者夜行：三分钟夺卷
- 目标：把当前可玩的阶段 5 原型整理成可上传 itch.io 的发布候选版本，并完成一次完整回归。
- 当前状态：Web 与 Universal macOS 发布候选、页面封面、音频电平分析和回归验证均已完成。

## 执行顺序

### 1. 发布基础

- 整理项目说明、操作方式、胜负规则和素材授权记录。
- 确认主场景、字体、音频和插件文件都在项目内。
- 检查敏感文件、临时文件和不应发布的调试内容。

### 2. 导出准备

- 检查本机 Godot 4.7.2 的导出模板和可用平台。
- 创建最小的导出配置；如果模板未安装，只生成明确的安装清单，不伪造导出成功。
- 为 itch.io 准备独立的发布目录，不覆盖源项目。

### 3. 完整回归

- 运行阶段 3、阶段 4、阶段 5 的冒烟测试。
- 启动主场景，检查资源导入、中文显示、音效节点、倒计时、死亡重开和胜利路径。
- 检查导出候选目录中的文件大小和启动入口。

### 4. 发布文档

- 编写 itch.io 页面所需的简介、操作说明和建议标签。
- 保留 `docs/asset_licenses.md`，说明外部素材、字体和生成音效来源。
- 记录不能自动完成的步骤，例如 itch.io 登录、上传和最终页面确认。

## 边界

- 不自动上传到 itch.io。
- 不创建持续运行的后台任务，不修改系统启动项。
- 不创建 Git 提交或推送，除非用户明确确认。
- 发现影响玩法的错误时先修复并重新回归，不用“看起来能运行”代替验证。

## 交付结果

- `docs/release_checklist.md`
- `docs/itch_page_draft.md`
- 本地发布候选目录或明确的导出阻塞原因。
- 更新后的 `task_plan.md`、`findings.md` 和 `progress.md`。
