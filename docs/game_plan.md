# 《忍者夜行：三分钟夺卷》游戏计划

## 一、游戏概念

这是一个俯视角 2D 小型动作收集游戏。玩家控制忍者进入一张被敌人占据的地图，在 3 分钟内收集 3 个卷轴并回到出口。

## 二、第一版核心循环

1. 从入口开始。
2. 使用方向键或 WASD 移动。
3. 使用近距离攻击清理挡路的敌人。
4. 收集 3 个卷轴。
5. 找到出口并返回。
6. 成功则显示通关时间，失败则可以重新开始。

## 三、第一版范围

### 必做

- 1 张小型地图。
- 1 个可控制的忍者。
- 1 种基础敌人。
- 3 个卷轴拾取物。
- 1 个出口。
- 玩家生命值、计时器和卷轴数量 UI。
- 胜利、失败和重新开始。

### 可选

- 第二种远程敌人。
- 一个小 Boss。
- 金币或回血道具。
- 屏幕震动、受击闪烁和粒子特效。

## 四、建议场景结构

- `Main`：游戏状态、计时器和重新开始。
- `World`：地图、碰撞和出口。
- `Player`：移动、攻击、生命值和受击。
- `Enemy`：追踪玩家和接触伤害。
- `ScrollPickup`：卷轴收集逻辑。
- `HUD`：生命值、时间和卷轴数量。
- `ResultPanel`：胜利和失败状态。

## 五、素材策略

- 主要角色、敌人、地图、道具、UI 和音频使用 Ninja Adventure 素材。
- 第一版保持一个素材包的视觉风格，不混用大量不同画风的资源。
- 将外部素材整理到 `assets/characters`、`assets/enemies`、`assets/tilesets`、`assets/items`、`assets/ui` 和 `assets/audio`。
- 只复制需要的文件，避免把示例项目中的工程配置覆盖到当前项目。

## 六、开发顺序

1. 建立文件夹和资源导入结构。
2. 创建地图和玩家场景。
3. 实现移动、碰撞和摄像机跟随。
4. 加入敌人追踪和攻击。
5. 加入卷轴、出口和计时器。
6. 加入 HUD、结算界面和重开。
7. 加入音效、特效和难度调整。
8. 测试并打包 itch.io 版本。

## 七、验收条件

- 双击运行项目后可以直接开始游戏。
- 玩家可以完成“收集 3 个卷轴并返回出口”的任务。
- 敌人、碰撞、生命值、计时器和重开逻辑没有明显错误。
- 游戏在 3 至 5 分钟内可以完成一局。
- 资源授权信息和发布文件已整理。
