# 《忍者夜行：三分钟夺卷》游戏计划

## 一、游戏概念

这是一个俯视角 2D 小型动作收集游戏。玩家控制忍者闯过五张被敌人占据的地图，每关收集 3 个卷轴并回到出口，五关共用 3 分钟和一条生命值。

## 二、第一版核心循环

1. 从第一张地图入口开始。
2. 使用方向键或 WASD 移动，Space 近战攻击。
3. 每关收集 3 个卷轴并进入出口，第一关出口会转到第二张地图。
4. 躲避追踪敌人和远程弹体，接近后用近战攻击反击。
5. 第五关出口完成任务；生命耗尽或总计时归零则失败。

## 三、第一版范围

### 必做

- 有操作说明的标题页和开始入口。
- 五张短小地图及关卡切换。
- 1 个可控制的忍者。
- 近战追踪敌人和远程攻击敌人。
- 每关 3 个卷轴拾取物。
- 1 个出口。
- 玩家生命值、计时器和卷轴数量 UI。
- 胜利、失败、暂停、重开和返回标题。
- 暂停菜单中的主音量滑块，并保存音量设置。

### 可选

- 第二种远程敌人。
- 一个小 Boss。
- 金币或回血道具。
- 屏幕震动、受击闪烁和粒子特效。

## 四、建议场景结构

- `Main`：游戏状态、计时器和重新开始。
- `TitleScreen`：游戏入口和操作说明。
- `World`：地图、碰撞和出口。
- `Player`：移动、攻击、生命值和受击。
- `Enemy`：追踪玩家和接触伤害。
- `ScrollPickup`：卷轴收集逻辑。
- `HUD`：生命值、时间和卷轴数量。
- `ResultPanel`：胜利和失败状态。
- `PausePanel`：暂停、音量、重开和返回标题。

## 五、素材策略

- 主要角色、敌人、地图、道具、UI 和音频使用 Ninja Adventure 素材。
- 第一版保持一个素材包的视觉风格，不混用大量不同画风的资源。
- 将外部素材整理到 `assets/characters`、`assets/enemies`、`assets/tilesets`、`assets/items`、`assets/ui` 和 `assets/audio`。
- 只复制需要的文件，避免把示例项目中的工程配置覆盖到当前项目。

## 六、开发顺序

1. 建立文件夹和资源导入结构。
2. 创建标题页并说明操作。
3. 创建第一张地图、玩家和近战敌人。
4. 实现移动、碰撞、卷轴、出口和计时。
5. 加入 HUD、结算、重开和暂停音量菜单。
6. 创建第二、第三、第四、第五张地图并串联五关进度。
7. 加入远程攻击敌人和应对方式。
8. 打磨动画、音效、难度并更新 itch.io 发布包。

## 七、验收条件

- 运行项目后先显示标题页和操作说明，开始按钮与 Enter 都能进入关卡。
- 玩家可以完成“收集 3 个卷轴并返回出口”的任务。
- 敌人、碰撞、生命值、计时器和重开逻辑没有明显错误。
- 暂停时计时和游戏逻辑冻结，音量调整保存后在下次启动仍可恢复。
- 游戏在 3 至 5 分钟内可以完成一局。
- 资源授权信息和发布文件已整理。
